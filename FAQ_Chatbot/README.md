
# AI-Based College FAQ Chatbot

## Project Description
This project is an AI-based chatbot that answers frequently asked college-related questions.

It uses Natural Language Processing (NLP) to understand user questions and find the most similar FAQ.

## Technologies Used
- Python
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit

## Features
- Answers college-related questions.
- Text preprocessing using NLP.
- Matches questions using cosine similarity.
- Provides automatic chatbot responses.
- Simple interactive web interface.

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

4. Open the local URL shown in the terminal.
